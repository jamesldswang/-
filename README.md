# 刺蝟養成記 🦔

一個單檔、免安裝的網頁刺蝟養成小遊戲。用瀏覽器打開 `index.html` 就能玩，進度自動存在瀏覽器裡。

## 怎麼玩

1. 用瀏覽器開啟 `index.html`，幫刺蝟取個名字。
2. 照顧牠的五項狀態：🍽️ 飽足、😊 心情、🫧 清潔、⚡ 體力、❤️ 健康。
3. 狀態維持得好，刺蝟就會慢慢長大：**刺蝟寶寶 → 幼年 → 少年 → 成年刺蝟**。

### 照顧動作

| 按鈕 | 效果 |
|---|---|
| 🐛 麵包蟲 | 心情大增，飽足小增；吃太飽還硬塞會傷健康 |
| 🥣 刺蝟飼料 | 飽足大增 |
| 🍎 蘋果丁 | 飽足、心情小增，並回復一點健康 |
| 🎡 跑滾輪 | 消耗體力換心情，**晚上跑有夜貓子加成** |
| 🤚 摸摸 | 心情增加；心情太差時牠可能會縮成刺球 |
| 🛁 洗澡 | 清潔回滿，但會有點不開心 |
| 🧹 清便便 | 清掉地上的便便（也可以直接點便便） |
| 💤 睡覺 | 回復體力；白天睡恢復更快 |
| 💊 看醫生 | 大幅回復健康，但心情會變差 |

### 小提醒

- 遊戲時間：真實 4 分鐘 = 遊戲 1 天，有日夜變化。
- 刺蝟是夜行性動物：晚上玩更開心，白天睡覺恢復更快。
- 關掉網頁後時間仍會流逝（離線時狀態下降速度減半），記得回來看看牠。
- 飢餓、髒亂或心情太差會讓健康下降，健康太低會長得很慢。

## 特色

- 手繪線條風刺蝟，有側面走路、正面發呆／被摸、縮成球三種姿勢
- 每個成長階段體型與毛色都不同
- 純 HTML + Canvas + JavaScript，無任何外部依賴
- 使用 `localStorage` 自動存檔，可隨時「重新開始」
